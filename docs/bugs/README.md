# Bugs

One file per bug: `BUG-001-short-name.md`. Use this layout:

```
# BUG-001: short name
Symptom: what you saw
Repro steps: 1. ... 2. ...
Root cause: why it happened
Fix: what changed (commit link)
Verification: how you proved it is fixed (test name, manual check)

## Log
- YYYY-MM-DD: what was tried, what worked, what did not
```

Never rewrite the log. Add new lines at the bottom.
